Style Tile

This page documents the design system used across this project: the palette, the typographic scale, and the spacing rules, so every page pulls from the same set of decisions instead of improvising fresh choices each time.

Palette

Primary, Midnight Violet #2A1F2D. Header background and heading color that passes with white text at 15.76:1.

Neutral text #3B2C35 on neutral background #F2F2F2. Body text and page background that passes at 14.07:1.

Accent, Mint Leaf #59C9A5. Passes the test with dark text at 7.74:1.

CTA background, a brighter version of the accent called Tropical Mint, #56E39F. Dark text on this lighter shade checks at 9.67:1.

Type Scale

Heading 1, 2.25rem (36px)

Heading 2, 1.75rem (28px)

Body text, 1.25rem (20px)

Spacing

  • main: max-width 1000px, centered with margin: 0 auto, padding 40px top and bottom, 20px left and right.
  • The call-to-action button: padding 10px top and bottom, 20px left and right, plus margin-top 5px to separate it from whatever sits above it.
